Bug-fix release of **BetterFxSound**, after a full debug pass on the fork's multiple-output features.

> **Pre-release.** This build is for testing. Please report problems in [Issues](https://github.com/xp3z41x/BetterFxSound/issues).

## Fixes

### Left / Right / Mono outputs
- An output set to Left or Right no longer replays the other side's old audio after power off/on or a switch to another output with the same format.
- Switching outputs no longer sends a short, loud, unprocessed stereo burst to the newly chosen device. BetterFxSound no longer makes a real device the Windows default during a switch, not even briefly.
- A channel-mode change is heard at once, instead of only after the output's delay.

### Microphone delay sync
- Room noise is no longer accepted as a beep. A device that can't be heard, such as a monitor without speakers, is reported as "not measured" instead of getting a made-up delay.
- 1.5 s of silence plays before the first beep, so devices that wake up slowly don't miss it.
- Outputs with a long delay can now be measured.
- The beep is louder when the Windows volume is low.
- Sync refuses to start, with a clear message, when the Windows volume is muted or at 0, when nothing is playing, or while the output setup is changing.
- The result names enabled outputs that weren't connected. Cancelling says "Sync cancelled."

### Multiple outputs
- Fixed a crash when a Bluetooth device disconnected while it was playing.
- Each device's own Windows volume is restored when BetterFxSound stops using it, even after an unplug, a crash or a Bluetooth reconnect. Before, it could come back at 100%.
- A delay change on an output takes effect at once instead of drifting in over many seconds.
- After a pause, every output starts again in sync.

### Window, command line, MCP server and installer
- The installer now closes BetterFxSound properly before an upgrade, repair or uninstall, so Windows sound and device volumes are left as they were. A silent upgrade restarts the app if it was running.
- Opening and closing an output's settings no longer rounds a synced delay to 5 ms.
- Output popups follow light/dark theme changes and show their tooltips.
- `--output-volume` and `--output-delay` accept a quoted device name, such as `--output-volume="JBL Clip 4":50`.
- fxmcp no longer closes an FxSound it started itself, and `set_output_device` reports an error for a name that matches no output.

## Installing

Download `BetterFxSound-1.0.1-x64-setup.exe` below and run it. It upgrades 1.0.0 in place and keeps your settings, presets and output setup.

## Known issues

- **The installer is not code-signed.** Windows SmartScreen will warn that it comes from an unknown publisher. Click **More info**, then **Run anyway**.
- **The Surround effect blends the two sides.** With Surround above 0, an output set to Left or Right also plays part of the other side, quietly. Set Surround to 0 for a clean Left/Right split.
- **USB or HDMI as the low-latency output.** When BetterFxSound uses a USB or HDMI device as its internal low-latency output, that device can drift slowly out of sync with the others, about 80 ms per hour. Bluetooth devices aren't affected.
- The fork's new text is in English in every language.
- x64 only. Windows 7/8 are not supported.
- On the first start after an upgrade, the app resets its effect engine state (`HKCU\SOFTWARE\DFX`) to the selected preset, as FxSound does on every version change. Your presets and app settings are kept.
