First release of **BetterFxSound**, a fork of [FxSound](https://github.com/fxsound2/fxsound-app) that plays your enhanced audio on **several outputs at the same time**.

> **Pre-release.** This build is for testing. Please report problems in [Issues](https://github.com/xp3z41x/BetterFxSound/issues).

## What's new: multiple outputs

The output handling was reworked from the ground up:

- **Outputs grid in the main window.** Every playback device is a tile you can switch on or off. Several outputs can play at once.
- **No "main" output any more.** Outputs are one flat list and every enabled output is equal. With all of them off, BetterFxSound plays silence.
- **Windows master volume on every output.** The system volume keys and slider control all enabled outputs together.
- **Per-output settings.** Each tile's gear button opens its **volume** (a trim on top of the master volume), **delay** (0–500 ms) and **channel** settings.
- **Microphone delay sync.** BetterFxSound can measure each enabled output with your microphone and set the delays so all speakers play in sync, aligned to the slowest one.
- **New command-line options:** `--enable-output`, `--disable-output`, `--output-volume=<device>:<0-100>` and `--output-delay=<device>:<0-500>`. `--output` now means "enable only this output". `--status` reports every output's state (enabled, present, volume, delay, channel mode) in `status.json`. The fxmcp MCP server has matching tools. See [Command line options](https://github.com/xp3z41x/BetterFxSound/blob/main/docs/COMMAND_LINE_OPTIONS.md).

## Installing

Download `BetterFxSound-1.0.0-x64-setup.exe` below and run it. It needs 64-bit Windows 10 or 11 and administrator rights.

- **If official FxSound is installed**, setup closes it, uninstalls it and installs BetterFxSound in its place. Setup never deletes your FxSound **settings and presets** (`%APPDATA%\FxSound`, `HKCU\SOFTWARE\DFX`).
- The **FxSound Audio Enhancer** virtual audio driver is installed, or kept if it is already there.
- BetterFxSound installs to `C:\Program Files\BetterFxSound`. The program file is still named `FxSound.exe`, so existing scripts and the command-line options keep working.
- To go back to official FxSound, uninstall BetterFxSound and install FxSound from [fxsound.com](https://www.fxsound.com).

## Known issues

- **The installer is not code-signed.** Windows SmartScreen will warn that it comes from an unknown publisher. Click **More info**, then **Run anyway**. The included audio driver is the original, Microsoft-signed FxSound driver.
- x64 only. There is no ARM64 or 32-bit build yet, and Windows 7/8 are not supported.
- On the first start after installing, the app resets its effect engine state (`HKCU\SOFTWARE\DFX`) to the selected preset, as FxSound does on every version change. Your presets and app settings are kept.
- In-app links such as Help and Support still point to fxsound.com. "Check for updates" opens this Releases page. There is no automatic updater.
